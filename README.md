# 抖音抬头版 · douyin-tt

用于个人学习的抖音电视客户端，支持 Android 5.0 及以上。电脑保留官方网页登录会话，与电视配对完成凭证同步和互动请求。

- [Android 客户端](android/README.md)
- [电脑同步工具](companion/README.md)
- [架构](docs/architecture.md) · [开发](docs/development.md) · [贡献](CONTRIBUTING.md)

检查和构建仅通过 GitHub Actions 手动执行。默认只检查，显式启用 `build_apk` 才编译并生成 Actions 产物；不提供 Release 安装包。本地禁止编译和测试。
